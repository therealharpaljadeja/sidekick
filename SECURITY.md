# Security

Sidekick listens to your microphone and decides what appears in your screen recordings, so privacy bugs matter. If you find one, such as Sidekick showing up in a recording while **Hide from screen recordings** is on, or audio leaving your Mac, please report it privately through [GitHub security advisories](https://github.com/therealharpaljadeja/sidekick/security/advisories/new) rather than a public issue.

Fixes go into the latest release only.
